Before we start

Two things you need to hear

Cold texting that list is a legal risk

  • Texting or calling skip-traced numbers falls under the federal do-not-call law.
  • Fines run $500 to $1,500 per message. On a 200-person list that math gets ugly fast.
  • You said yourself around 70% of a PropStream list is on the registry.
  • Scrubbing those numbers is built into Phase Three, and I won't skip it. Done right this is completely manageable.

Blue-bubble texting doesn't last

  • Project Blue and tools like it run against Apple's rules and get shut off every so often.
  • Fine to use if the numbers work, but I'll build it so you can swap to another provider without redoing your whole outbound.
